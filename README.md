# 👻 מודול אבטחת Ghost
**כלי חיזוק אבטחת Windows ו-Azure מבוסס PowerShell**

> **חיזוק אבטחה פרואקטיבי עבור נקודות קצה של Windows וסביבות Azure.** Ghost מספק פונקציות חיזוק מבוססות PowerShell שיכולות לעזור להפחית וקטורי תקיפה נפוצים על ידי השבתת שירותים ופרוטוקולים מיותרים.

## ⚠️ הסתייגויות חשובות

**נדרש בדיקות**: תמיד בדקו את Ghost בסביבות שאינן ייצור תחילה. השבתת שירותים עלולה להשפיע על פונקציות עסקיות לגיטימיות.

**אין ערבויות**: בעוד Ghost מתמקד בוקטורי תקיפה נפוצים, אף כלי אבטחה לא יכול למנוע את כל ההתקפות. זהו רכיב אחד באסטרטגיית אבטחה מקיפה.

**השפעה תפעולית**: פונקציות מסוימות עלולות להשפיע על פונקציונליות המערכת. בדקו כל הגדרה בקפידה לפני הפריסה.

**הערכה מקצועית**: עבור סביבות ייצור, התייעצו עם מומחי אבטחה כדי להבטיח שההגדרות מתאימות לצרכי הארגון שלכם.

## 📊 הנוף הביטחוני

נזקי רנסומוור הגיעו ל-**57 מיליארד דולר ב-2025**, כאשר מחקרים מצביעים על כך שהתקפות מוצלחות רבות מנצלות שירותי Windows בסיסיים ותצורות שגויות. וקטורי תקיפה נפוצים כוללים:

- **90% מתקריות רנסומוור** כוללות ניצול RDP
- **פגיעויות SMBv1** אפשרו התקפות כמו WannaCry ו-NotPetya  
- **פקודות מאקרו במסמכים** נשארות שיטת מסירה עיקרית של תוכנות זדוניות
- **התקפות מבוססות USB** ממשיכות לפגוע ברשתות מבודדות
- **שימוש לרעה ב-PowerShell** גדל באופן משמעותי בשנים האחרונות

## 🛡️ פונקציות אבטחת Ghost

Ghost מספק **16 פונקציות חיזוק Windows** בנוסף ל-**אינטגרציית אבטחת Azure**:

### חיזוק נקודות קצה של Windows

| פונקציה | מטרה | שיקולים |
|----------|---------|----------------|
| `Set-RDP` | מנהל גישת שולחן עבודה מרוחק | עלול להשפיע על ניהול מרחוק |
| `Set-SMBv1` | בקרת פרוטוקול SMB ישן | נדרש למערכות ישנות מאוד |
| `Set-AutoRun` | בקרת AutoPlay/AutoRun | עלול להשפיע על נוחות המשתמש |
| `Set-USBStorage` | הגבלת התקני אחסון USB | עלול להשפיע על שימוש לגיטימי ב-USB |
| `Set-Macros` | בקרת ביצוע מאקרו Office | עלול להשפיע על מסמכים עם מאקרו |
| `Set-PSRemoting` | ניהול PowerShell מרוחק | עלול להשפיע על ניהול מרחוק |
| `Set-WinRM` | בקרת Windows Remote Management | עלול להשפיע על ניהול מרחוק |
| `Set-LLMNR` | ניהול פרוטוקול רזולוציית שמות | בדרך כלל בטוח להשבית |
| `Set-NetBIOS` | בקרת NetBIOS על TCP/IP | עלול להשפיע על יישומים ישנים |
| `Set-AdminShares` | ניהול שיתופי מנהל | עלול להשפיע על גישה לקבצים מרחוק |
| `Set-Telemetry` | בקרת איסוף נתונים | עלול להשפיע על יכולות אבחון |
| `Set-GuestAccount` | ניהול חשבון אורח | בדרך כלל בטוח להשבית |
| `Set-ICMP` | בקרת תגובות ping | עלול להשפיע על אבחון רשת |
| `Set-RemoteAssistance` | ניהול סיוע מרחוק | עלול להשפיע על פעולות Help Desk |
| `Set-NetworkDiscovery` | בקרת גילוי רשת | עלול להשפיע על דפדוף רשת |
| `Set-Firewall` | ניהול חומת אש של Windows | קריטי לאבטחת רשת |

### אבטחת ענן Azure

| פונקציה | מטרה | דרישות |
|----------|---------|--------------|
| `Set-AzureSecurityDefaults` | הפעלת אבטחת Azure AD בסיסית | הרשאות Microsoft Graph |
| `Set-AzureConditionalAccess` | תצורת מדיניות גישה | רישוי Azure AD P1/P2 |
| `Set-AzurePrivilegedUsers` | ביקורת חשבונות מורשים | הרשאות מנהל כללי |

### אפשרויות פריסה ארגונית

| שיטה | מקרה שימוש | דרישות |
|--------|----------|--------------|
| **ביצוע ישיר** | בדיקות, סביבות קטנות | זכויות מנהל מקומי |
| **Group Policy** | סביבות דומיין | מנהל דומיין, ניהול GP |
| **Microsoft Intune** | התקנים מנוהלים בענן | רישוי Intune, Graph API |

## 🔍 פרטי פונקציות

### פונקציות חיזוק ליבה

#### שירותי רשת
- **RDP**: חוסם גישת שולחן עבודה מרוחק או מחליף יציאה
- **SMBv1**: משבית פרוטוקול שיתוף קבצים ישן
- **ICMP**: מונע תגובות ping לסיור
- **LLMNR/NetBIOS**: חוסם פרוטוקולי רזולוציית שמות ישנים

#### אבטחת יישומים  
- **מאקרו**: משבית ביצוע מאקרו ביישומי Office
- **AutoRun**: מונע ביצוע אוטומטי מנשאים נתיקים

#### ניהול מרחוק
- **PSRemoting**: משבית סשני PowerShell מרוחקים
- **WinRM**: עוצר Windows Remote Management
- **Remote Assistance**: חוסם חיבורי סיוע מרחוק

#### בקרת גישה
- **Admin Shares**: משבית שיתופי C$, ADMIN$
- **Guest Account**: משבית גישת חשבון אורח
- **USB Storage**: מגביל שימוש בהתקני USB

### אינטגרציית Azure
```powershell
# התחברות לטנט Azure
Connect-AzureGhost -Interactive

# הפעלת ברירות מחדל אבטחה
Set-AzureSecurityDefaults -Enable

# תצורת גישה מותנית
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# ביקורת משתמשים מורשים
Set-AzurePrivilegedUsers -AuditOnly
```

### אינטגרציית Intune (חדש ב-v2)
```powershell
# התחברות ל-Intune
Connect-IntuneGhost -Interactive

# פריסה דרך מדיניות Intune
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## ⚠️ שיקולים חשובים

- **סביבת מעבדה**: בדקו את כל ההגדרות בסביבה מבודדת תחילה

- **תכנית חזרה**: ודאו שאתם יכולים לבטל שינויים במידת הצורך
- **תיעוד**: רשמו אילו הגדרות עובדות לסביבה שלכם

### השפעה פוטנציאלית
- **פרודוקטיביות משתמש**: הגדרות מסוימות עלולות להשפיע על זרימות עבודה יומיומיות
- **יישומים ישנים**: מערכות ישנות יותר עלולות לדרוש פרוטוקולים מסוימים
- **גישה מרוחקת**: שקלו השפעה על ניהול מרחוק לגיטימי
- **תהליכים עסקיים**: ודאו שההגדרות לא שוברות פונקציות קריטיות

### מגבלות אבטחה
- **הגנה מדורגת**: Ghost הוא שכבה אחת של אבטחה, לא פתרון מלא
- **ניהול שוטף**: אבטחה דורשת מעקב ועדכונים רציפים
- **הדרכת משתמשים**: בקרות טכניות חייבות להיות משולבות עם מודעות אבטחה
- **התפתחות איומים**: שיטות תקיפה חדשות עלולות לעקוף הגנות נוכחיות

## 🎯 דוגמאות תרחישי התקפה

בעוד Ghost מתמקד בוקטורי תקיפה נפוצים, מניעה ספציפית תלויה ביישום ובדיקה נכונים:

### התקפות בסגנון WannaCry
- **מיתון**: `Set-Ghost -SMBv1` משבית את הפרוטוקול הפגיע
- **שיקול**: ודאו שאין מערכות ישנות הדורשות SMBv1

### רנסומוור מבוסס RDP
- **מיתון**: `Set-Ghost -RDP` חוסם גישת שולחן עבודה מרוחק
- **שיקול**: עלול לדרוש שיטות גישה מרחוק חלופיות

### תוכנה זדונית מבוססת מסמכים
- **מיתון**: `Set-Ghost -Macros` משבית ביצוע מאקרו
- **שיקול**: עלול להשפיע על מסמכים לגיטימיים עם מאקרו

### איומים מועברי USB
- **מיתון**: `Set-Ghost -USBStorage -AutoRun` מגביל פונקציונליות USB
- **שיקול**: עלול להשפיע על שימוש לגיטימי בהתקני USB
